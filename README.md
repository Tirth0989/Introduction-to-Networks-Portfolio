# Introduction to Networks Portfolio

This repository contains a completed **COMP503 / COMP608 – Introduction to Networks** lab workbook. It documents practical Cisco networking work involving device access, IOS administration, IPv4 and IPv6 configuration, remote management, security, troubleshooting, and configuration backup and recovery.

## Repository contents

| File | Description |
| --- | --- |
| [Introduction to Networking Lab Book](Lab-Book/Introduction-to-Networking-Lab-Book.docx) | Completed practical workbook containing lab activities, command explanations, configurations, screenshots, reflections, and feedback. |

## Labs covered

| Lab | Topic |
| --- | --- |
| 1 | Physical access to a Cisco switch using a console connection |
| 2 | Cisco IOS command-line modes, navigation, and context-sensitive help |
| 3 | Securing administrative CLI access with banners, console passwords, and enable secrets |
| 4 | Managing running and startup configurations, password encryption, saving, reloading, and erasing configurations |
| 5 | Configuring remote router access using Telnet |
| 6 | Configuring remote switch access using Telnet and a switch virtual interface (SVI) |
| 7 | Building and testing a small IPv4 network with a router, switch, default gateway, and login protection |
| 8 | Securing remote access with SSH, RSA keys, local authentication, and login blocking |
| 9 | Backing up and restoring startup configurations with TFTP |
| 10 | Building an IPv6 network using `/64` addressing, link-local addresses, IPv6 routing, Telnet, and SSH |

## Skills demonstrated

- Cisco console access and terminal emulation
- IOS CLI modes, navigation, and command help
- Hostname, banner, console, and privileged-access configuration
- Password encryption and secure administrative access
- Running and startup configuration management
- IPv4 addressing, subnetting, default gateways, and connectivity testing
- Switch virtual interface configuration
- Telnet and SSH remote management
- SSH version 2, RSA keys, and local user authentication
- Login protection and basic device hardening
- TFTP configuration backup and restoration
- IPv6 `/64` addressing, link-local addresses, and IPv6 routing
- Troubleshooting with `ping`, `show ip interface brief`, `show ipv6 interface brief`, and related IOS commands

## Evidence included

The workbook includes completed hands-on activities, addressing plans, Cisco IOS commands, configuration evidence, screenshots, written explanations, and reflections on the practical work.

## Viewing the workbook

Download the `.docx` file and open it in Microsoft Word or LibreOffice Writer. GitHub may not render the full document in the browser because it contains extensive formatting and embedded screenshots.
